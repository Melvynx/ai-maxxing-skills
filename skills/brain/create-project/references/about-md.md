Skeleton for every hub and project `About.md`.

```markdown
---
status: active   # active | paused | done
updated: <today, YYYY-MM-DD>
---

# <Name>

<One paragraph: what it is and the goal, then what it covers and what it does not ("Not here: ... (see <project>)"), so every fact lands in one project.>

## Key info
- Links, ids, accounts, paths

## Current state
- What is done, what is next (short)

## Decisions
- <YYYY-MM-DD> <what was decided>, because <why>
- <YYYY-MM-DD> Not <option>, because <why>
```

Leave `## Decisions` out until there is a first decision with its reason; `/done` adds it.
